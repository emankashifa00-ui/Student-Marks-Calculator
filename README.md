# Student-Marks-Calculator
My first C++ beginner project – A student marks calculator using conditional statements and logical operators.
-This program takes marks of five subjects and calculates:
•Total marks
•Obtained marks
•Percentage
•Individual subject pass/fail status
•Overall result
-Concepts Used
•Variables and Data Types
•User Input and Output
•Arithmetic Operators
•If-Else Statements
•Logical AND (&&)
•Logical OR (||)

This project is part of my journey towards learning programming and improving my problem-solving skills.
